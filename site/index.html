01 / MODEL

Your choice stays yours

Sol low or medium and Astra low can work as MAIN. Luna handles independent tasks when the host supports delegation. No forced model or effort changes.

02 / CONTEXT

Use the actual window

GPT-6 models may advertise 872k. The installer checks a local model catalog, respects lower ceilings and shows context remaining in the CLI.

03 / SSD

Move data with a way back

Encrypted SSD, independent backups, a quiet copy and a tested rollback. A symlink or green config is never proof that the desktop app works.

Install

Give your agent the URL.

Ask it to inspect the public repo, show you a read-only preview, apply the approved config and read the result back. This does not relocate your SSD data automatically.

Install NoBrainer Codex from https://github.com/nobrainer-tech/nobrainer-codex. Read README.md and docs/spec.md. Run python3 install.py --check, then --apply for the configuration I authorize. Preserve my manually selected MAIN model, effort, sign-in and chats. Use NoBrainer.Tech Flow (https://github.com/nobrainer-tech/nobrainer-tech-flow). For SSD relocation, follow docs/external-ssd.md and stop at the backup/encryption owner gates.

Python 3.11+; macOS, Windows and Linux. Install Codex separately using the official distribution first. The CLI status line is not the desktop UI; desktop context is available with /status.

Configured 872k is not a way to expand a smaller model. 15 slots is a ceiling, not a promise that 15 workers will always run. Official desktop startup without an SSD needs its own verified gate.
